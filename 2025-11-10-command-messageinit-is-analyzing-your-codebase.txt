> I'd like to add support for the suite of herb tools (https://herb-tools.dev/): herb-lint and herb-format. these tools
should run on eruby files similar to the existing erblint tool already implemented. ideally they should only run when the
extension is .html.erb (herb is a pun on html erb).

herb-format is a "fixer" which rewrites .html.erb files.

herb-lint is a linter. it is not yet a fixer (they are working on a --fix flag but it's not released yet).

they are distributed via npm, so their CLIs will live in node_modules/.bin when installed in a project. they may also be
globally installed. they should not do anything when the tool is not installed. prettier is also distributed via npm, so
it may be useful to look at how the prettier linter/fixer is implemented to see how they make sure to only run when
installed.

it's important to follow the testing conventions of the project and test this well.

the interface for running herb-format is simply `herb-format path/to/file.html.erb` which should rewrite the file.

the interface for running herb-lint is also `herb-lint --format json path/to/file.html.erb`. The json output format looks
like this:
